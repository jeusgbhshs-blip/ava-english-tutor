# Ava — AI 英语口语与资料带读

新增 iPhone 开发工程（iOS 16+）、豆包语音移动端修复、100 MiB 知识库导入和私人 HTTPS 服务部署配置。构建、测试与上架前条件见 [iOS 开发与发布路线](docs/ios/README.md)；当前服务数据仍为个人单用户空间。

Ava 是在本机运行的英语练习网站：选择角色说英语、按个人目标生成三节课、导入资料逐句学习，并在课后总结和复习单词。

**产品定位：供个人持续使用的本地英语学习空间。** 当前在完整源码恢复基础上，继续打磨语音、资料、复习和个人设置之间的交互。个人交互版本已修复一批异步状态、焦点、返回、输入保留和数据一致性问题；真实云语音、设备兼容和教学效果仍需独立验收。

## 快速启动

先安装 Node.js 24；交接包不包含 Node 可执行文件，也不需要 `npm install`。

```bash
node server.js --port 5180 --host 127.0.0.1
```

打开 **http://127.0.0.1:5180/mobile**。端口被占用时，以终端实际输出的端口为准。

- `/mobile` 是当前主产品入口，桌面优先，也保留响应式布局。
- “我的 → 模型与语音设置”进入现有完整配置表单；保存后可返回主界面。
- `/` 是旧桌面版，保留模型设置及历史功能；不应直接删去。
- 不配置模型 Key 时，部分文字对话、总结和内容使用规则演示，不能据此判断真实模型效果。
- 主入口已按原产品选择关闭浏览器合成语音。实时通话需要豆包实时语音配置；角色点读还依赖独立 TTS 的有效凭据，不能假定一定有系统语音回退。

macOS 也可运行 `bash start.command`。`npm start` 会尝试打开浏览器；打不开时可按终端地址手动访问。

## 已有能力

| 能力 | 实际实现与边界 |
|---|---|
| 数字人角色 | Elena、Maya、Hikari；分层图片与 WebGL 动画、音量驱动口型 |
| 口语对话 | PTT 回合控制、实时 ASR 字幕、模型回复、独立 TTS、手动打断与恢复逻辑 |
| 个性化课件 | 一句话目标、固定三课、跟读/场景/挑战、顺序解锁与断点续学 |
| 知识库 | 文本/文件/网页导入、预览校对、本地 BM25、可选模型增强与重排 |
| 资料带读 | 选资料、逐句教学提示、原文对照与点读；超长文仍受上下文预算限制 |
| 英语书库 | 六本书的三十段学习节选、每日进度、重点词同步；进度仅在当前浏览器 |
| 复习 | 词库、到期复习、四档自评、会话恢复、配对/听音/拼写小游戏 |
| 学习总结 | 快速规则总结、模型总结、关键词/句型、词表与记忆写入 |

“跟读评分”当前比较目标句和转写文本，不是音素或声学发音评测。“课程完成”记录参与步骤，不等于已证实掌握。书库“分钟数”按每次完成固定增加十分钟，不是实际计时。

## 数据与运行范围

数据默认写入 `data/`，可用 `AVA_DATA_DIR` 指定。模型凭据、知识库、记忆和学习记录都在该目录或浏览器 localStorage 中。代码仓库与交付包排除这些个人数据。

```bash
AVA_DATA_DIR=/absolute/path/to/ava-data node server.js --host 127.0.0.1
```

默认只在本机使用。源码可以公开，运行中的个人实例包含资料与模型凭据，应保持本机访问。`scripts/share.sh` 是历史局域网分享入口，使用它会把同一份个人实例提供给网络中的其他设备。

图片 OCR 依赖 macOS Vision；Linux/Windows 会明确返回不支持。TXT/MD、DOCX/PPTX 与部分 PDF 有本地提取实现；扫描 PDF 当前需先转成图片再在 macOS 导入，复杂排版需检查提取结果。

## 测试

```bash
npm run check       # 所有随包 JavaScript 的语法检查
npm test            # 原有单元测试 + 恢复与个人交互回归
npm run test:e2e    # 真HTTP/WS桥 + 本机假上游，不使用真实模型Key
npm run test:ui     # 原Chrome/CDP UI套件，需本机Chrome与相应权限
```

Linux 的 E2E 会验证图片 OCR 明确拒绝且不产生空文档；macOS 会验证图片真提取。该差异不表示已经补齐跨平台 OCR。

GitHub Actions 配置位于 [test.yml](.github/workflows/test.yml)，使用 Node 24 运行语法、单元与本机假上游契约检查。首次远端成功运行前，不把“CI 配置已存在”表述为“GitHub CI 已绿”。
