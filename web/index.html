欢迎来到 Ava 英语角

Ava 是一个像朋友一样的数字外国人：想聊什么就聊什么，聊完还会帮你整理总结和今天的重点单词。

  • 允许麦克风

    点下方「开始体验」后允许麦克风权限，Ava 才能听到你说话。浏览器只会把语音交给本机的语音识别。

  • 想聊什么就聊什么

    工作、天气、追剧、烦恼…… 中英夹着说也可以，Ava 会接住你的话，顺便纠正语法、教你更地道的说法。

  • 听不懂、不会说就说中文

    直接说或打字说中文，或者点麦克风旁的「中文求助」按钮：Ava 会先听懂你的意思，再教你这句英文怎么说。

  • 聊完自动整理总结

    点「结束对话并总结」，Ava 会整理本次话题、亮点、纠错与重点单词，并自动收进今日单词表。

当前浏览器不支持语音识别（建议使用 Chrome / Edge）。你可以直接用下方输入框打字练习，其余功能完全正常。

麦克风音频只在本机浏览器处理；无 Key 时全部功能可体验（演示模式）。
