# Ava 个人交互第一轮修复与演示验收

日期：2026-11-01 UTC（北京时间 2026-11-02）。开发分支：`feat/personal-interaction`。本轮基于恢复提交 `5945f18f4f5aeddb480f1e9cf03e3c6916a0ae5a`，原始源码基线 `725c004bc7bd1bfbb215a8cd75cbe6b239c12853` 保留。

## 1. 用户方向与本轮结果

Ava 面向个人持续使用。开发重点是个人的对话、课程、资料、复习和偏好之间是否连贯、可信、可恢复。README 与当前路线已按这一方向更新，移除了以多人、会员与支付为下一步的安排；个人页的会员占位改为真实的个人学习说明。

本轮深入检查并修复已经复现的代码错误，启动真实项目的本地预览，用浏览器实际操作关键流程。没有替换原有角色图片，没有重写框架，也没有把静态效果图冒充可工作的产品。主入口仍保留不使用浏览器合成语音的原产品选择。

“达到苹果交互水平”在本轮转化为可检查的标准：操作立即回应，等待和失败说明事实，取消能真正停止，旧任务不打断新任务，键盘焦点连续，背景不抢操作，动效有目的且尊重减少动态效果偏好。本轮完成的是第一批实证修复，不能据此声称整个产品已达到该质量目标。

## 3. 代码组织与修改边界

保持原生 ESM 架构，新增两个小模块：

- `web/js/mobile/dialog.js`：共享弹窗的归属、背景隔离、焦点和回调生命周期。
- `web/js/mobile/navigation.js`：覆盖层与浏览器历史的同步。

`interaction.css` 在原有样式之后加载，保留原有角色资产和布局基础。`app.js` 处理外壳键盘、历史和初始加载；`core.js` 处理共享读取／保存时序；`call.js`、`kb.js`、`review.js`、`screens.js` 各自维护业务请求归属。

后端改动集中在 `plans.js`、`lessonGen.js`、`assistant.js`、`kb.js` 与设置入口。计划再生成使用修订号，完成课件不被重置；新课件生成失败时仍能追溯旧内容。个人难度同步计划时，如果计划写入失败，尝试回滚设置并返回错误，不宣称保存成功。

所有新增行为回归位于 `test/personal-*.test.mjs`。模拟 DOM、接口、WebSocket 和音频设备用来控制故障时序；它们不替代真实浏览器与真实语音验收。

真实浏览器观察到当前环境 WebGL 角色动画不可用时会使用静态人物图；这只能证明回退可用，不能证明动画运行流畅。浏览器扩展自身的日志与项目的错误分别判断。

## 6. 仍需验收或下一轮修复

- **真实语音与设备**：此 HTTP 演示地址不是麦克风安全上下文，未进行真麦克风、TTS 音色、自动播放、真实弱网和长通话验收。使用本机 localhost 或 HTTPS，并配好服务权限后，再按目标设备验证。
- **苹果设备与辅助功能**：当前实际浏览器为桌面 Chrome；iPhone／iPad／macOS Safari、触摸、真实读屏器和系统减少动态效果未实测。CSS 已尊重对应偏好，不等于整个 WebGL 动画系统已完成适配。
- **学习质量**：文字模型未配置时使用规则演示。转写匹配仍不等于声学发音测评，课程参与完成不等于掌握；示例反馈不能用于判断真实教学质量。
- **资料深度**：超长资料的教学游标、上下文分配和尾段可达性仍需完善；Linux 预览不支持原有 macOS Vision 图片 OCR。
- **数据恢复**：损坏 JSON 的保留与提示、统一备份／导入、浏览器与服务器进度的完整恢复仍待实现。
- **不确定结果的重试**：复习评分请求如果服务端已写入但响应丢失，跨重试的幂等性仍需专项修复；本轮解决的是已确认评分后的游标与动画窗口。

当前路线详见 [ROADMAP.md](../audit/ROADMAP.md)。后续以用户在演示中指出的具体页面、动作和预期为单位持续修改，不以主观“完成百分比”代替验收。
