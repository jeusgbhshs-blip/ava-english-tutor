## 今日已完成的修复及边界

- 新知识库页面使用二进制 File 请求，不再在 iPhone 中先把整个文件转成 base64。默认源文件上限为 **100 MiB**，`AVA_MAX_UPLOAD_MB` 可配置为 1–500 MiB；文件选择与服务端查询到的限制一致。上传会写入临时磁盘、受超时和实际字节数限制，并在结束或失败时清理。上传和提取串行，避免同时处理多份大文件挤占内存。见 `lib/fileUpload.js`、`web/js/mobile/kb.js`。
- **源文件容量不等于可教学文本容量。** 每份资料仍最多保留 60,000 字符；界面预先说明此限制，提取截断时显示警告。不会声称上传 100 MiB 文件就完整学习了全书。旧 `/api/doc/upload` 与旧 JSON 上传仍保持 12 MiB 合同。
- DOCX/PPTX 只解压需要的正文 XML，不解压嵌入图片。单个解压条目/流上限 16 MiB，总量上限 64 MiB；损坏或超限内容明确失败。PDF 文本操作符改为线性扫描，避免损坏数组触发正则回溯。见 `lib/docExtract.js`。
- 增加 TSV，补齐 ODT、HTML 的跨平台文本提取。网页导入与 HTML 文件共用 `lib/htmlText.js` 的线性文本提取，不执行脚本，移除脚本、样式和导航，保留常用实体和段落换行。
- 网页导入默认只允许公开 HTTP(S) 页面：拒绝 URL 凭据、内网/回环/链路本地/保留 IP，验证全部 DNS 地址，连接时固定已验证地址，每次重定向重新验证。最多 5 次重定向、8 MiB 响应和 30 秒总时间；只接收 HTML/纯文本。请求未压缩响应，对仍返回压缩数据的站点明确提示使用文件上传。见 `lib/urlImport.js`。`AVA_ALLOW_PRIVATE_URL_IMPORT=1` 仅用于明确的本地测试，不应在公开部署中启用。
- 服务访问码、来源验证、临时 WebSocket 票据和 iOS Keychain 接入已由主开发流程补齐。提供商密钥保留在服务端；`publicSettings()` 返回掩码与配置状态，不返回完整密钥。`scripts/build-ios-web.mjs` 只打包网页资源和可公开的服务地址，不打包服务器数据目录。

- 原生应用的学习缓存已按规范化服务地址分区，切换后台时重新加载对应分区；断开连接会清除 Keychain 访问码，保留明确说明的学习数据。见 `web/js/scoped-storage.js`、`web/js/native-bootstrap.js` 与 `test/scoped-storage.test.mjs`。该修复避免跨服务混用本机缓存，但不改变同一后台仍为单用户共享空间的事实。

## PDF 和语音能力的真实含义

PDF 提取仍是轻量文本提取器，并不是完整 PDF 排版引擎。已验证普通文本 PDF、包含大图片的文本 PDF、压缩流、文本数组与转义。扫描 PDF、复杂字体映射、表格和多栏顺序不能保证正确；扫描版无可提取文字时会给出提示。重要学习资料应校对提取结果。对于损坏或达到解压上限的文件，应拆分或转换为 TXT/DOCX，而不是关闭容量保护。

豆包实时对话和点读是不同的调用链。实时语音支持 App ID 加 API Key 或 Access Token（`lib/volcRealtime.js:21`）；独立点读只从 `AVA_TTS_API_KEY` 或 `volc.apiKey` 取凭据（`lib/tts.js:42`），使用单独的 TTS 资源。因此“实时语音连接成功”不能证明点读授权可用。本轮已按官方二进制接口文档将默认模型修正为 O2.0 `1.2.1.1`（Dacey 英语音色）。旧保存值 `3.0` 会明确提示，Seeduplex 3.0 的另一套 JSON 协议未在本轮实现。运行环境需 Node.js 24+，并核对实际账号支持的模型版本和音色。此次没有使用真实用户密钥调用云端服务。
