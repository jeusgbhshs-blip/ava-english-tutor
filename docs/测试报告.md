## 9. v1.4 豆包实时语音 3.0（架构与验证）

### 9.1 架构与数据流

```
浏览器（麦克风 48k → 重采样 16k PCM 640B/20ms）
  └─ WebSocket /ws/voice（本机）──▶ 本地服务桥 server.js
        ├─ 浏览器只发 {type:start|stop|interrupt} + PCM；**不接触任何火山密钥**
        ├─ 服务端读取 settings.volc（Key 仅存本机 data/settings.json 600）
        └─ lib/volcRealtime.js ──(X-Api-App-Id + X-Api-Key/Access-Key + Resource-Id)──▶ 火山实时语音 WS
              事件：StartConnection(1)→50→StartSession(100)→150→上行音频 200
              ← ASR 451（{text,is_final}）/450/459、Chat 550/559、TTS 350/352(24k PCM raw)/359、错误 51/153/599
  ◀─ 桥把火山事件转成浏览器 JSON：{type:'ready'|'asr'|'chat'|'audio-start'|'audio-end'|'error'|'ended'}
       + 二进制 24k PCM 帧；数字人用 setSpeechLevel(0..1) 按播放振幅驱动口型
  └─ 每轮用户 final 后调 POST /api/coach（文本模型只分析不回复；失败/无 Key 规则版）→ 纠正/中文求助/生词卡
```

- **语音引擎可切换**：设置页「语音引擎（高级）」单选「浏览器内置语音（默认）/ 豆包实时语音 3.0」；豆包模式仅接管「说/听」，教学层（coach 反馈、中文求助、结束总结、单词表、SRS）仍由本应用负责。
- **测试连接** `POST /api/volc/test`：真实建连 → StartConnection → StartSession → 等 SessionStarted（≤20s）→ FinishSession/FinishConnection，返回 `{ok,latencyMs,model,speaker}` 或中文错误；未填凭据给中文提示。
- **coach 分析** `POST /api/coach`：有文本模型 Key 走严格 JSON「只分析不回复」，失败/无 Key 规则版（`detectCorrections`/`buildChineseHelp`），中文输入 corrections 必空。
