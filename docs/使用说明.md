# Ava — AI 数字人英语老师 · 使用说明

> Ava 是一个**本地运行、单人使用**的 AI 英语口语练习应用：**一个会说中文解释、像朋友一样的数字外国人**，陪你随便聊、帮你纠正语法、把重点单词自动整理进「今日单词表」并安排间隔复习。
> **听不懂、不会说时直接用中文**——Ava 会先听懂你的意思，再教你这句英文怎么说。
> 还能**上传英文文档/图片**，让 Ava 读完后用中文分析、用英文带你互动问答。
> 语音可选**浏览器内置**（默认）或**豆包实时语音 3.0**（更低延迟、更自然，需自备火山引擎凭据）。
> 对话字幕**中英双语**：Ava 说的英文下面有中文翻译，你说的英文下面也有中文翻译。
> 豆包语音模式默认**专注对话**：不再逐轮弹「你应该怎么说」，纠错和重点词都收进结束总结与今日单词表。
> 全部数据只保存在你自己的电脑上，不经过任何第三方服务器（除了你自己配置的 AI 模型接口）。

## 1. 快速开始（30 秒）

### 启动

1. 打开文件夹 `english-tutor`；
2. **双击 `start.command`**（或在「终端」里执行 `bash start.command`）；
3. 看到一个黑色终端窗口打印 `Ava ready at http://127.0.0.1:5180`，并且 **Chrome 自动打开**该地址，就启动成功了；
4. 关闭终端窗口 = 停止服务。

> 第一次双击 `start.command` 若被 macOS 拦截（提示"无法打开，因为来自身份不明的开发者"），
> 在文件上 **右键 → 打开 → 仍要打开** 一次即可，之后可直接双击。
>
> 必须用**桌面版 Chrome**（Safari / Firefox 的语音识别兼容性不足；Chrome 的语音识别需要联网使用 Google 服务）。

### 首次进入：允许麦克风

1. 页面加载后，点底部中间的大麦克风按钮 🎤；
2. Chrome 顶部弹出「要允许 127.0.0.1 使用你的麦克风吗？」→ 点 **允许**；
3. 如果误点了「阻止」：点地址栏左侧的 🔒 图标 → 麦克风 → 改为「允许」→ 刷新页面。

> 也可以用**键盘输入**（Dock 右侧的输入框）代替说话，不需要麦克风也能练。

## 2. 三种使用状态：演示模式 / 真 AI / 语音

### 2.1 演示模式（默认，零配置）

不填 API Key 也能**完整体验全部功能**：Ava 用内置教学脚本回复英文、给出纠错、生词和中文鼓励，也能做对话总结、生成今日单词表。

- 顶部显示「演示模式」小标签；**点它可直接打开设置填 API Key**；
- 回复是脚本化的、**不会真正理解你说话的具体内容**，适合先熟悉界面；
- 想要真正"听懂你说话"的 AI 朋友 → 填 API Key（下一节）。

### 2.2 升级为真 AI（填入 API Key）

1. 点右上角 **⚙️ 设置**；
2. 在「AI 模型」里填写：
   - **Base URL**：模型接口地址。可直接从输入框下方的预设里点选常用服务：
     - DeepSeek：`https://api.deepseek.com/v1`，模型 `deepseek-chat`
     - OpenAI：`https://api.openai.com/v1`，模型 `gpt-4o-mini`
     - Kimi：`https://api.moonshot.cn/v1`，模型 `moonshot-v1-8k`
     - 通义千问：`https://dashscope.aliyuncs.com/compatible-mode/v1`，模型 `qwen-plus`
     - 本地 Ollama：`http://127.0.0.1:11434/v1`，模型 `qwen2.5:7b`（无需联网、无需 Key）
   - **模型**：服务商控制台里显示的模型名；
   - **API Key**：粘贴你的密钥；
3. 点 **测试连接**，显示「连接成功 · xx ms」即配置正确；
4. 点 **保存并生效**。顶部「演示模式」标签消失，Ava 变成真 AI。

**安全说明：**

- API Key 只保存在本机 `data/settings.json`（权限 600），**页面永远不回显原文**，只显示 `sk-…后4位` 提示；
- 想清除 Key：设置 → 「清除已保存的 Key」→ 保存；
- 复制本应用给他人时，**不要**把 `data/` 目录一起发出去。

### 2.3 语音 / 键盘

- **点麦克风**：开始聆听（按钮变红/发光），说完停顿约 1.2 秒自动结束并发送；
- **再点一次**：提前结束聆听并发送；
- **键盘输入**：点底部输入框，打字后回车/点发送；
- Ava 的回复会**边流式出字幕边朗读**，数字人会跟着口型说话；
- 设置里可开「**自动连续对话**」：Ava 说完自动重新开始聆听，适合沉浸练习。

### 2.4 听不懂、不会说？直接用中文（中文求助）

- **文本输入**：输入框里直接打中文（例如「我今天很累，不知道怎么说」）→ 发送即可，不需要任何切换；
- **语音**：点 Dock 上的「**中文求助**」按钮（中图标）→ 语音识别切到中文，提示「现在可以说中文，Ava 会教你怎么用英文说」→ 说中文；本条发送后自动切回英文识别；
- Ava 会先确认理解你的意思，再给出**你想说的那句英文**、**意群拆解**和**中文提示**；右侧「中文求助卡」可点 🔊 朗读、点「**跟我读**」跟读打分（跟读不进入对话历史）；
- 中文输入不会当成英文语法错误（**不会出现纠错卡**），也不会被空洞夸奖；状态栏会显示「Ava 正在教你怎么用英文说…」。

### 2.5 高级语音引擎：豆包实时语音 3.0（可选）

默认使用**浏览器内置语音**（始终可用、零配置）。想让 Ava 的声音更低延迟、更自然，可切换到豆包实时语音 3.0：

1. 先在[火山引擎控制台](https://console.volcengine.com/)开通「**端到端实时语音大模型**」，拿到 **App ID** 与 **API Key（或 Access Token）**，并确认控制台里可用的**模型版本**与**音色 ID**；
2. 打开 Ava → 右上角 **⚙️ 设置** → 底部「**语音引擎（高级）**」→ 选「**豆包实时语音 3.0**」；
3. 填写：
   - **App ID**：火山控制台应用管理里的 ID；
   - **API Key** 或 **Access Token**（二选一即可）；
   - **模型版本**：默认 `3.0`（以你的控制台实际开通版本为准，如 `1.2.1.1`、`2.2.0.0`）；
   - **音色 ID**：默认 `en_female_dacey_uranus_bigtts`（英文女声，以控制台音色列表为准）；
   - **服务地址**（默认官方地址）与**资源 ID**（默认 `volc.speech.dialog`）一般不用改；
4. 点「**测试连接**」：显示「连接成功 · 3.0 · Nms」即配置正确；失败会给出中文原因（如鉴权失败 / 模型不支持 / 音色不匹配）；
5. 点「**保存并生效**」。顶栏出现「豆包实时语音」徽标，之后点麦克风即进入豆包实时语音通话：字幕取 ASR 识别与模型回复文本，Ava 的声音由豆包实时生成，数字人按播放振幅同步口型。

**注意与隐私**

- 豆包模式会把你的**录音音频**发送到火山引擎（这是该服务的工作方式）；原始音频不保存，凭据只保存在本机 `data/settings.json`（权限 600），界面永不回显密钥原文，浏览器端**不接触**任何火山密钥（由本机服务转发）；
- 教学层（纠错、中文求助、生词、结束总结、今日单词表、SRS）仍由本应用负责；失败/未配置时会**自动回退浏览器内置语音**并给中文提示；
- 其它模式（单词闯关/跟读打分/阅读讲解等）的朗读仍走浏览器 TTS，不受影响。

### 2.6 双语字幕 + 豆包模式「专注对话」

**双语字幕（双方）**

- Ava 的回复：英文字幕（主）+ **中文翻译第二行**（略小、次要样式）；
- 你说的话：英文识别字幕（主）+ **中文翻译第二行**；如果你直接说中文，则中文就是原文、英文为翻译；
- 翻译方式（服务端自动选择，浏览器不接触密钥）：优先用已配置的**豆包凭据**开一个「文本模式」实时会话做翻译（只发文字、不产生语音），其次用已配置的**文本模型 Key**；两者都没有或翻译失败时**静默只显示英文**，不弹错误、不影响对话；
- 翻译是异步的，中文可能比英文晚 1–2 秒出现；开始新一轮会清空上一轮中文，避免串行错位；
- 隐私：翻译只把你当前这一句/这一段文字发给你自己配置的豆包/文本模型服务，不会发送其它内容或保存额外数据。

**豆包语音模式的「专注对话」**

- 使用豆包实时语音且处于自由对话/角色扮演时，Ava 说完后**不再显示逐轮纠错/更好的说法/生词/鼓励卡**，右栏显示「专注对话模式 · 结束对话后可看总结」；
- 想逐轮看纠错：把设置里的语音引擎切回「浏览器内置语音」即可恢复（原有反馈功能不变）；
- 例外：当你主动用**中文**说/打字求助时，仍会出现「中文求助」卡（只在你明确求教时出现）；
- 结束对话的**总结**和**今日单词表**不受影响，纠错与重点词仍会整理在那里（所以建议聊完点「结束对话并总结」）。

## 3. 五个教学模式

顶部 Tab 切换模式，右上角「等级」选择 CEFR 难度（A1 入门 → C1 高级），影响 Ava 的用词、句子长度和语速。

### 💬 自由对话 Free Talk（默认 · 数字外国朋友）

- **不用选话题**：Ava 像朋友一样，聊工作、学习、天气、情绪、旅行、美食、电影、家人、周末计划……**想聊什么就聊什么**；
- 右侧面板给「聊天灵感」chips（点一下自动填入输入框，可改可忽略）、「换一个灵感」「中文提示」；
- 每次回复都是「**先直接回答/回应你刚说的具体内容** + 一点她自己的观点/生活 + 一个追问」，不会自顾自换话题、不会用反问回避问题、也不会空洞夸奖；说得短也没关系，她会接着聊；
- 聊 **2 轮以上**可点「**结束对话并总结**」（见下一节），让 Ava 整理本次重点并生成今日单词表。

### 🎯 单词闯关 Vocabulary

- 选词库主题 → **词卡**：看单词、音标、中文释义、例句，点 🔊 听发音；
- 跟读该单词 → 系统给发音评分；
- 随后进入**选择题 / 拼写测验**；
- 答错的词自动进入**错词本**，按间隔复习算法（SRS）安排下次复习；
- 进度面板里的「今日复习」会提示到期的单词。

### 🎙️ 跟读打分 Pronunciation

- 从句子库选一句（或使用 Ava 给的示范句）；
- 点麦克风跟读 → 显示 **0–100 分 + 星级 + 逐词高亮**（正确/接近/漏读三种颜色）；
- 下方给**中文发音提示**（咬舌音、词尾吞音、连读等），可反复重读刷新成绩。

### 🎭 角色扮演 Role-play

- 选场景：咖啡店点单 / 机场值机 / 求职面试 / 酒店入住；
- Ava 进入角色（咖啡师、值机员、面试官、前台）和你对话；
- 右侧列出本场景**目标句清单**，完成一项打勾；
- 对话几轮后 Ava 会给一句收尾总结。

### 📄 阅读讲解 Reading（v1.3 新增）

上传任意英文材料，Ava 先在本机读懂，再用中文帮你拆解、用英文带你互动问答：

- **支持格式**：txt / md / csv / json / log、doc / docx / rtf / odt / html、pptx / pptm、pdf、png / jpg / jpeg / webp / gif / bmp / heic / tif（单个文件 ≤12MB；图片 OCR 仅 macOS）；
- **上传后自动分析**：右侧面板出现中文**摘要**、**核心要点**、**重点词汇卡**（点 🔊 听发音）、**理解题**列表；无 Key 时标注「演示分析」；
- 点「**开始讲解**」：Ava 用英文介绍材料并问第一题；你可以用英文回答或随时提问，她会结合原文讲解、纠错并追问；
- 「**朗读原文**」用浏览器语音分段朗读建议片段；「**下一题**」推进理解题；
- 上传/分析中状态：「Ava 正在读这份材料…」；失败会有中文提示与重试；
- **隐私**：原始文件只在本机解析、**不落盘**；只保存提取后的文字与分析到本机 `data/docs/`，不上传任何第三方（除你自己配置的模型 API 会收到用于讲解的文本片段）；
- 扫描版 PDF（纯图片）无法提取文字时会提示你「上传它的截图（图片）或 txt/docx 版本」；手机上拍的英文照片可直接上传走系统 OCR。
- 刷新页面后最近文档会从本机恢复；删除文档需二次确认（同时删除提取文字与分析）。

## 4. 结束对话 → 自动总结 → 今日单词表

这是 Ava 的核心学习闭环：**聊完就整理，重点词自动进词表**。

### 4.1 结束对话并总结

1. 在「自由对话」里聊 **2 轮以上**；
2. 点右侧面板或底部 Dock 的「**结束对话并总结**」；
3. 几秒后弹出「本次对话总结」，包含：
   - **中文总结**：聊了什么、整体表现、一条具体进步点；
   - **话题 chips**：本次聊到的 1–3 个话题；
   - **做得好的地方 / 可以更自然的地方**：引用你的原句给出具体建议；
   - **这次的纠错**：原句 → 更自然的说法 + 中文解释（没错误则不显示）；
   - **重点单词 3–8 个**：英文单词/短语 + 音标 + 中文释义 + 英文例句 + 「为什么值得记」；
   - **中文鼓励**；
   - 底部「**查看今日单词表**」/「**继续聊**」。

> 重点单词会**自动加入今日单词表**，并作为新词进入间隔复习（SRS）；「继续聊」会开始新一轮对话（历史不跨轮，但词表/进度持续累积）。
>
> 演示模式下总结由内置规则生成；填了 API Key 后由大模型生成（失败会自动降级为演示总结，不中断使用）。

### 4.2 今日单词表

- 顶栏新增 **📖 单词本按钮**（带当日新增词数徽标）；
- 弹窗按日期分组、**今天置顶**（昨天/更早显示日期标签）；
- 每条显示：单词、音标、中文释义、例句、「为什么值得记」，可点 🔊 朗读；
- 跨天累积：第二天总结的词会进入新的日期分组；
- 想手动往词表里加词也可以（接口 `POST /api/wordbook`，普通使用无需关心）。

## 5. 进度与复习

点右上角 **📊 进度**：

- **连续学习天数**（streak）、累计句子数、累计分钟数；
- **掌握单词数**（复习到较高记忆等级的词）；
- **最近 7 天**学习柱状图；
- 到期复习单词入口。

数据保存在本机 `data/progress.json`（进度/SRS）与 `data/wordbook.json`（今日单词表），删除对应文件即可重置。

## 6. 整屏游戏化网页 /mobile（v1.7）

**整屏游戏化**的新界面（不是手机壳/App 模拟器）：`#app` 铺满整个浏览器窗口，桌面 **1440×900 / 1920×1080 / 1280×800** 为主用尺寸，窗口缩放自适应，430 宽手机也兼容；和旧版桌面页 `/` **共存**（旧版保持不变）。

- **全屏人物 + 游戏 HUD**：对话首页是满屏人物"世界"背景 + 角色信息卡（名字/城市/性格标签/音色/场景）+ 3 个角色切换器 + 「去聊聊」；底部 HUD 导航 5 页，**键盘 1–5** 可直接切页；
- **三张人物原图**：Elena / Maya / Hikari 严格使用你提供的三张插画（`/assets/characters/{elena,maya,hikari}.jpg`，原图保留在 `docs/assets/characters/source/`），**不改画/不改色**，只做 cover 裁切与 UI 暗角/光晕/粒子覆盖；
- **通话页**：全屏人物口播画面 + 游戏 HUD（角色名/城市、计时/信号、场景标签、底部对话框、右下说话/文字/挂断），挂断 → 通话总结弹层 → 回「对话」页；
- **点击式 PTT（v2.3）**：通话页默认「点击说话」——点**大麦克风**开始录音（红脉冲/计时/16 段波形/「✕ 取消」），**再点同一个麦克风**结束并提交这一句（面板没有「完成」按钮），Ava 回答后回待机；**空格**开始/结束（输入框聚焦时不拦截），**Esc** 取消本轮；
- **麦克风自检（v2.3）**：进通话页自动检测麦克风——「麦克风正常」+ 10 段音量条随说话跳动；持续 2s 无声→「没有检测到声音」+设备/静音键/权限提示；权限被拒→「重新授权麦克风」+「改用文字输入」，允许后恢复；识别失败（网络不可达/被打断/没声音）都是单条中文内联提示，不堆叠弹窗；豆包 403 期间自动走浏览器 PTT（计时不重置），恢复后同一 PTT 用角色音色；
- **通话字幕/对话条（v1.8）**：她的回复和你说的话都有中英双语气泡；底部新增游戏式**角色对话条**（角色名 + 状态 + 英文当前句 + 中文译文，说完保留最后一句）；多轮消息自动滚到最新（手动上翻回看不打断），翻译超时最多自动重试 3 次；
- **口播动画（P0）**：`web/js/talking-head.js` 用 WebGL 对原图做**局部形变**（呼吸/头部轻摆/眨眼/嘴部开合，`setSpeechLevel` 驱动），**不改人物素材**；WebGL 不可用时自动静态人物图兜底；当前是 2D 局部形变动画，**不是音素级 lip-sync**；
- **角色分层实时动效（方案 A，v2.0）**：三张原图已拆成前景/背景两层（Lead 用 macOS Vision 自动分层，`web/assets/characters/layers/{id}-fg.webp` + `-bg.webp`），通话口播时**发丝/衣摆会轻摆**、背景轻微视差，脸部保护不拉扯，眨眼/视线/口型保持；**分层失败的自动回退单图引擎**、无 WebGL 回退静态图，不白屏不崩溃；已知限制：前景遮罩非逐根发丝、极细飘散发丝可能留在背景层不跟动、2D 无 3D 转头、大动作幅度有限；P1 可升级 bitHuman Expression 2 真视频数字人（任意角色 WebGPU 实时口型，可继续用我们的豆包语音）/ Spatius / Live2D 等；演示动图 `docs/assets/demo-elena-live.gif`；
- **P1 后续（真视频/实时口型，待你选型）**：bitHuman Expression 2（任意角色、浏览器 WebGPU 实时口型，可继续用豆包语音）、Spatius 等实时视频数字人、Live2D/VRM 分层模型（观感更游戏、制作量大）。

先在本机启动服务（`node server.js`），然后：

- **桌面**：`http://127.0.0.1:5180/mobile`（1440/1920 全屏体验最佳，F11 全屏更像游戏画面）；
- **同一 Wi-Fi 局域网**：手机浏览器打开 `http://<电脑的局域网 IP>:5180/mobile`（如 `http://192.168.1.10:5180/mobile`；macOS 需允许防火墙放行）；
- **远程 / HTTPS**：浏览器只在 **HTTPS 或 localhost** 下允许麦克风，也才支持「添加到主屏幕」全屏。可用内网穿透/隧道（Cloudflare Tunnel、ngrok 等）把 5180 映射为 https 域名，手机打开 `https://<你的隧道域名>/mobile`；
- **添加到主屏幕（PWA）**：iOS Safari「分享 → 添加到主屏幕」；Android Chrome「菜单 → 添加到主屏幕」。之后可全屏运行（`manifest.webmanifest` 已配置 standalone、图标与主题色）。

功能一览：

- **底部 5 Tab**：课程 / 对话 / 助手（Ava）/ 趣玩 / 我的；
- **对话**：3 位角色卡横滑画廊——Elena（伦敦·画廊策展人，温柔/艺术）、Maya（纽约·广告创意总监，直爽/幽默）、Hikari（东京·虚拟偶像练习生，元气/二次元），各自有不同豆包音色；点「**去聊聊**」进入全屏通话页：角色形象 + 计时 + 场景标签（可切换）+ 双方中英双语气泡 + 长按/点击说话、文字输入、静音、翻译开关、提示、挂断；
- **语音**：优先走豆包实时语音（需要设置里已配置豆包凭据，手机浏览器授权麦克风），失败自动回退浏览器语音；说话后 ASR 字幕 + 中文翻译，Ava 回复中英双语；挂断 → **通话总结**（复盘/纠错/重点词，重点词进今日单词表）；
- **助手**：6 个快捷 chips（创建计划 / 更新我的计划 / 快速复习 / 场景练习 / 学习偏好 / 我要反馈）或直接打字；会按你的意图创建/更新学习计划、跳转场景、打开单词表；
- **课程**：展示学习计划的阶段进度与场景入口；没有计划时会引导你去助手创建；
- **趣玩**：词义配对小游戏（点一个英文词 + 对应中文释义，配对成功加分，全对撒彩带，「换一局」重开）；
- **我的**：昵称/等级/学习目标、语音引擎状态、今日单词、已掌握、Ava Plus 占位。

**权限与隐私**

- 手机浏览器首次点说话会请求**麦克风权限**；非 HTTPS 页面浏览器会拒绝录音（此时可用文字输入）；
- 两套界面共用同一台电脑上的本机数据（设置/进度/今日单词表/计划/文档）；豆包凭据只保存在电脑本地 `data/settings.json`，手机端不接触密钥；
- 使用隧道访问时，音频/文本会经过你选择的隧道服务，请使用自己可信的服务。

## 7. 知识库 / 发散讨论 / 兴趣档案（v1.8）

- **入口**：/mobile →「助手」→「我的知识库」；打开整屏知识库面板，可上传文件、导入网页、勾选材料讨论。
- **上传**：txt/md/csv/doc/docx/rtf/pptx/pdf/png/jpg，单文件 ≤20MB（本地解析，原文件不保存）；列表显示来源/类型/字数/切块/中英/摘要状态（pending→done，异步生成检索摘要）。
- **网页导入**：粘贴 http(s) 链接 → 后端抓取正文与标题入库；反爬/登录站点会失败并给中文提示。
- **讨论模式**（勾选 1–N 篇后）：「围绕知识库讨论」（grounded，必须引用材料，可对比多篇；通话页对话条上方显示引用卡片：标题+片段+匹配度）、「发散讨论」（divergent，以材料为起点延伸/联想/反例/跨领域）、「自由聊」（free，不强制引用）；通话页右上模式 chip 可切换。
- **对话导演与记忆**：每轮先规划角度/立场/是否追问，避免重复最近问题；角色职业/城市/爱好只是「视角」，不再硬拉话题；长期记忆（兴趣/事实/话题/摘要）存本机 `data/memory.json`，兴趣可从「我的」页读写。
- **隐私**：知识库与记忆只存本机 `data/kb`、`data/memory.json`；上传内容不会发给第三方，但围绕讨论/摘要增强会把相关片段发给你自己配置的 DeepSeek。
- **已知限制**：摘要异步（pending 时检索/引用可能为空，稍等或手动重新分析）；网页抓取依赖网络；引用卡片只在后端返回命中时出现；豆包实时语音若控制台资源未授权会回退浏览器语音（不影响文字讨论）。

## 9. 常见问题（FAQ）

### Q1：没有 API Key 能玩吗？

能，**演示模式完整可用**（对话、纠错、生词、总结、今日单词表、跟读打分、单词闯关、角色扮演全部可跑），只是回复是内置脚本，不是真正理解你的 AI。

### Q2：点麦克风没反应 / 提示权限被拒绝？

1. 确认使用的是**桌面版 Chrome**；
2. 地址栏左侧 🔒 → 麦克风 → 允许 → 刷新页面；
3. macOS：系统设置 → 隐私与安全性 → **麦克风** → 勾选 Google Chrome；
4. 检查系统输入设备是否选对（系统设置 → 声音 → 输入）；
5. 完全不想授权麦克风时：用键盘输入模式，除"跟读打分/语音识别"外都能用。

### Q3：语音识别一直"网络错误"？

Chrome 的语音识别（Web Speech API）依赖 Google 的在线语音服务：

- 需要能访问 Google 服务的网络环境；
- 挂代理时请确认代理为系统代理或全局模式，Chrome 能走代理；
- 若长期不可用，可改用键盘输入练习（功能不受影响）。

### Q4：Ava 不朗读 / 没有声音？

1. 检查系统音量和 Chrome 标签页是否静音；
2. 设置 → 英文音色 → 换一个音色，点「试听音色」；
3. macOS：系统设置 → 辅助功能 → 朗读内容，确认英文语音包已安装；
4. Chrome 限制"自动播放"：先点一下页面任意位置，再让 Ava 说话。

### Q5：提示"接口地址或模型名不正确 / API Key 无效"？

- 检查 Base URL 是否以 `/v1` 结尾（不同服务商要求不同，按预设填写最稳）；
- 检查模型名大小写与服务商控制台一致；
- 检查 Key 是否复制完整、是否过期/额度用完；
- 用「测试连接」快速定位；Ollama 本地模型需先 `ollama serve` 并拉取对应模型。

### Q6：为什么「结束对话并总结」没反应？

总结要求**至少聊过 2 轮**（你至少说过 2 句英文）。先多聊一句，再点按钮即可。

### Q7：总结/单词表数据存在哪里？想清空怎么办？

- 今日单词表：`data/wordbook.json`；
- 进度与 SRS：`data/progress.json`；
- 设置与 API Key：`data/settings.json`。
删除对应文件即可重置（删 `progress.json` 会清空连续天数与错词本；删 `wordbook.json` 只清单词表）。

### Q8：端口 5180 被占用 / 打开的是别的服务？

服务启动时会自动尝试 5180、5181、5182…，以终端里打印的 `Ava ready at http://127.0.0.1:xxxx` 为准，Chrome 会自动打开正确端口。
也可以手动指定：`node server.js --port 5190`。

### Q9：想彻底重置 / 换一台电脑迁移数据？

- 重置设置：删除 `data/settings.json`；
- 重置进度与单词表：删除 `data/progress.json`、`data/wordbook.json`；
- 迁移：把整个 `english-tutor` 文件夹（不含 `data/`）拷走即可，无需安装任何依赖。

### Q10：提示找不到 Node.js？

`start.command` 会自动在常见路径寻找 Node.js（本机默认路径、`node`、`/usr/local/bin/node`、`/opt/homebrew/bin/node`）。
若都没有：安装 Node.js 22+ 后重试，或把 node 的绝对路径写进 `start.command` 的检测列表。

### Q11：数据隐私？

- 应用只监听 `127.0.0.1`，局域网其他设备访问不到；
- 对话内容只会发送到你**自己配置**的 AI 模型接口（演示模式完全不联网）；
- 设置、进度、单词表只存本机 `data/` 目录。

### Q12：我说中文，Ava 能听懂吗？

- **演示模式**：内置 30+ 组高频中文表达（累了 / 不会说 / 听不懂 / 我喜欢 X / 我想要 X / 天气 / 周末…）可直接翻译成英文并给意群与提示；没覆盖到的中文会诚实说明「演示模式只能翻译常见表达」，并提示填入 API Key；
- **真 AI（已填 API Key）**：能理解任意中文，并用「确认理解 → 给英文表达 → 邀请跟读 → 继续对话」的方式教你怎么说；
- 无论哪种模式，中文求助都不会被当成英文错误记进纠错卡（`corrections` 为空）。

### Q13：为什么 Ava 有时会提示「演示模式只能按脚本接话」？

演示模式没有大模型，只能按内置脚本回复。当你的话没有匹配到脚本场景时，会**最多提示一次**「演示模式只能按脚本接话，填入 API Key 后 Ava 才能真的回答你」。点顶部「演示模式」徽标可直接打开设置填 Key，升级为真 AI 后即可自由问答。


### Q14：阅读讲解支持什么文件？会不会上传我的文档？

- 支持 **txt/md/csv/doc/docx/rtf/odt/pptx/pdf/图片（png/jpg/webp/heic 等）**，单文件 ≤12MB，提取文字超 6 万字符会截断并提示；
- **原始文件不会保存、也不会上传到第三方**：服务端只在本机提取文字，`data/docs/` 只存提取后的文字和分析结果；
- 图片 OCR 依赖 macOS 系统 Vision 框架（离线）；扫描版 PDF 无法提取文字时，请把页面截图成图片再上传。


### Q15：切到豆包实时语音后没声音 / 一直回退浏览器语音？

- 先在设置页点「**测试连接**」看具体中文错误：常见原因是 App ID/Key 错误、账号未开通「端到端实时语音」、模型版本或音色 ID 与控制台不一致；
- 确认网络能访问火山引擎服务地址，且代理没有拦截 WebSocket；
- 若连接失败，Ava 会**自动回退浏览器内置语音**并在顶部给出提示，不影响继续练习；可随时在设置里切回「浏览器内置语音」；
- 豆包模式只接管「说/听」，练习、纠错、总结、单词表等功能不受影响。


### Q16：字幕没有中文 / 豆包模式为什么看不到逐轮纠错？

- 中文字幕是异步翻译，通常 1–2 秒后出现在英文下面；若一直只有英文，说明翻译服务暂不可用（未配置豆包凭据/文本模型 Key，或网络失败）——**这是静默降级，不影响对话**，配置任一凭据后即可恢复；
- 豆包语音模式默认「专注对话」，不逐轮显示纠错卡；点「结束对话并总结」后可在总结与今日单词表中看到纠错与重点词；想要逐轮反馈可在设置里切回「浏览器内置语音」；
- 中文求助卡只在你说/打中文求助时出现。


### Q21：麦克风状态显示「没有检测到声音 / 权限被拒绝 / 识别服务不可达」怎么办？

- **没有检测到声音**：检查系统输入设备、麦克风是否被静音、是否选错输入源；靠近麦克风再说一次；
- **权限被拒绝**：点状态条里的「重新授权麦克风」再次允许；仍不行可到浏览器站点设置里把麦克风改为允许；
- **识别服务不可达**：浏览器语音识别依赖 Chrome 云端服务，国内网络可能不稳定；可换网络重试，或直接用「改用文字输入」聊天；
- 以上问题都可以点「改用文字输入」继续练习，不影响双语字幕/总结/知识库讨论；豆包语音恢复后在设置里切回即可使用角色音色。

### Q20：点了麦克风没反应 / 录音怎么结束？

- 通话页是**点击式 PTT**：点一下**大麦克风**开始录音（红色脉冲 + 计时 + 波形），**再点同一个麦克风**结束并提交这一句（面板没有「完成」按钮）；
- 键盘：**空格**开始/结束，**Esc** 取消本轮（输入框里打字时空格不会误触发）；
- 没听清时 Ava 会提示「没听清，再说一次」，不会崩溃；没有麦克风可点键盘图标改用文字输入；
- 豆包实时语音在控制台资源未授权时会自动回退浏览器语音，PTT 交互一致；恢复授权后同一个 PTT 会用角色音色。

### Q19：知识库上传了但讨论时没有引用 / 摘要一直 pending？

- pending 表示后台正在生成检索摘要（1–2s，UI 每 3s 轮询）；刚上传立刻讨论可能暂时检索不到，等状态变成 done 再试；
- 网页导入失败多为站点反爬/需要登录，会显示中文错误；可改用「复制正文保存为 txt」上传；
- 引用卡片只会在后端确实检索到材料时出现；「自由聊」模式通常不引用；grounded 未勾选材料会提示去知识库勾选；
- 豆包语音在控制台资源未授权时会回退浏览器语音，文字讨论与引用不受影响。

### Q18：/mobile 里人物在动，但口型不像真人 / 没有动画？

- v1.7 的 P0 口播是 WebGL **2D 局部形变**（呼吸、头部轻摆、眨眼、嘴部开合），不是音素级 lip-sync，观感上"像人在口播"但不会像真视频一样精确对嘴型；talking-head v1.8 已修复「眨眼一跳一跳 / 表情呆板」（单次平滑眨眼 + 缓慢视线漂移 + 极轻头部侧倾）；v1.8 还修复了「她的回复不落定/没有中文字幕/多轮看不到最新消息」等问题（双 final 去重、自动滚动、底部对话条、翻译重试）；
- 需要 WebGL：浏览器较旧/禁用 WebGL/无 GPU 时，会自动退回**静态人物图**（人物显示正常，只是不会动）；
- 若想要"真视频数字人"级口型：P1 计划接入 bitHuman Expression 2（任意角色、浏览器 WebGPU 实时口型，可继续用我们的豆包语音）、Spatius 等方案，或把三张插画做成 Live2D/VRM 分层模型——需要你选型后开发。

### Q17：手机打开 /mobile 不能录音 / 无法添加到主屏幕？

- 麦克风需要浏览器安全上下文：请用 **HTTPS**（隧道域名）或本机 localhost 访问；纯 http://局域网IP 只能文字聊天；
- 首次点说话请在弹窗里允许麦克风；iOS 若拒绝过，可到「设置 → Safari → 麦克风」重新允许；
- 「添加到主屏幕」同样需要 HTTPS；iOS 用 Safari 分享菜单，Android 用 Chrome 菜单；
- 如果页面打不开，确认手机和电脑在同一 Wi-Fi、电脑服务已启动、防火墙放行 5180；远程访问请先启动隧道。
