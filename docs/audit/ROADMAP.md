# Ava 个人产品开发与验收路线

用户已明确：Ava 面向个人持续学习。当前以本机使用、个人资料、连续学习和细致交互为产品边界；账号、多人租户、会员与支付不进入当前路线。

源码审查报告保留原始发现；本文件按用户最新方向更新。第一轮恢复见 [RECOVERY.md](RECOVERY.md)，个人交互修复与实际验收见 [PERSONAL-INTERACTION.md](../personal/PERSONAL-INTERACTION.md)。以下没有承诺未经测量的时间或成本。

## M0 · 可恢复的源码与工作基线

原始交接包、文件清单和 Git 基线保留。恢复后的源码、测试、启动说明与每轮验证证据一起交付。当前仍沿用原生 ESM，不为了换框架打断可用功能。

验收：原始源码可以追溯；新修复有明确问题和验证；演示、离线模拟、真实供应商和远端 CI 的结果分别记录。

## M1 · 一致、可控的个人交互

已推进：弹窗归属与键盘焦点、返回历史、旧异步结果隔离、个人表单草稿保留、复习快捷键、文字输入、真实保存反馈、目标修改后的课件版本，以及知识库导入状态。

后续逐页验收：

- 打开、取消、返回与继续都有可预测的结果，焦点和滚动位置连续。
- 可反复执行的操作不会重复提交；迟到结果不抢占正在进行的任务。
- Loading、成功、失败和演示模式对应实际状态，失败时保留已有内容。
- 在目标手机、桌面浏览器、键盘和触摸设备上分别检查点击区域、缩放、减少动态效果、对比度和长文阅读。
- 动画服务于反馈和层级；频繁操作保持快速，尊重系统减少动态效果偏好。

“苹果交互水平”是持续验收标准，不用一次 CSS 调整或通过单元测试来宣称完成。

## M2 · 真实语音课堂可靠性

已有多轮取消、连接代次、旧事件、媒体释放和总结归属修复。下一步使用实际配置和目标设备验证首句、长句、权限、自动播放、重连、打断和回到前台。

建议验收：记录 20 次独立首句、连续 5 分钟通话，以及断网、切后台和切换设备。记录连接、ASR 首字、回复首字、首音播放耗时。挂断后采音和播放都停止，迟到回调不影响下一次会话。

独立 TTS 与实时语音分别验收；保留主入口关闭浏览器合成语音的原产品偏好。没有真实声音的模拟测试只证明状态与协议逻辑。

## M3 · 可完整教授资料

原文存储、无模型状态、多图片逐张校对与文件限制已修复一部分。后续建立服务端 docId／段落／句子游标，明确当前句与附近上下文的预算，长文尾部仍可访问，重连后从准确句子继续。

验收：材料选择与讲解范围一致；自由聊不携带选中资料；引用和定位有稳定 ID；长文截断有准确说明；停止后不继续后台合成。网页导入和文件解码有合理的时间、大小和资源预算。

## M4 · 学习结果可信、数据一致

个人目标或等级更新会重新生成未完成课件，保留已完成内容及最近版本；旧读取和旧生成结果不能覆盖新计划。后续统一 review／progress／wordbook 的活动来源，区分练过、跳过、待复习与掌握。

验收：参与轮次不直接声称掌握；转写文本匹配与声学发音评分明确区分；统计能追溯到具体学习活动；失败重试不会重复评分或计数；换配置后可重做旧演示分析。

## M5 · 个人数据可带走、可恢复

统一导出与导入，覆盖服务端资料、课程、复习以及浏览器书库进度。导出默认不带 Key；保留数据版本和迁移记录。遇到损坏 JSON 保留原文件并报错，写入中断可恢复。

验收：新机器恢复后课程、资料和复习连续；重复导入不重置学习状态；损坏文件不会被静默覆盖；用户能明确了解记录保存在何处、哪些内容会发给所配置的云服务。

## 每轮交付方式

先复现具体问题，再做有边界的修复；以真实模块回归、协议检查和实际浏览器交互分别验证。保存可运行源码及证据，让用户在演示中逐页验收。已有用例只有在契约确实改变时更新，并在报告中解释原因。
